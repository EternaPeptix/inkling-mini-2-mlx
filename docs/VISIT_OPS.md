# Op inventory of one decode step (B=1, L=1), Loopling p3, MLX 0.32.4

Generated by `bench/glue_inventory.py` (`LOOPLING_COMPILE_DECODE=2`, `mx.disable_compile()` so the compiled `_l2_clip` /
`_softcapped_swiglu` appear as their element-wise primitives; graph walked with `mx.export_to_dot`). Raw primitive lists per
case (index + primitive, Broadcast included) are in `docs/visit_ops/<case>.txt`. Counts include ~1/3 free `Broadcast`/`Reshape`
nodes. The default path (`COMPILE_DECODE=1`) compiles the same segments (`mx.compile`), which fuses only element-wise runs;
the counts of real GPU kernels per visit are in the right-hand column of the table.

Dtype convention: residual stream `h` is bf16 (1,1,2304); `normed_residual`, block states `bs` (n,1,1,2304) and messages are f32.

## Differences for the other cases

* **Full attention layer** (273/234/338 prims): `attention_input` has 3 queries (`depth_attention` Q=3, output (1,1,3,2304)); there are three layer-norms (`q_input_layernorm`, `k_input_layernorm`, `v_input_layernorm`, each RMSNorm(weight bf16, x f32)+AsType bf16); k and v use `DynamicShortConvolution` (`weight_proj` QuantizedMatmul on k_in/v_in -> (1,1,8*4) bf16; Add static weights; ops: Slice x3 (window lags), Concatenate, Multiply, Sum (K=4), Add residual, Divide sqrt(9)) instead of the Metal conv kernel (that is the 112-primitive difference); `tau` (Multiply) on q and rel before `rel_logits_proj`, where `tau = 1 + 0.1*log(max((pos+1)/8192, 1))` is built once per step per layer (`FD._full_tau`: Arange, Add, AsType f32, Maximum, Log, Multiply, Add; 13 prims); no sliding-window mask terms; KV cache is a plain `KVCache` (concatenate/slice-update).
* **Looped pass > 0 (messages)**: before q/k/v input layernorms, `_mix_messages` = 3 `MessageGate`s (+ a fourth `mlp_message_gate` between mlp_input and post_attention_layernorm): per gate `RMSNorm(None)` on h and on message (f32), `Concatenate`, `AsType bf16`, `down_proj` is a bf16 `nn.Linear` (Matmul (4608->64)), `AsType f32`, two f32 `Matmul`s (`forget_gate_proj`, `message_gate_proj`, (64->2304)), `Tanh` x2, `Subtract 1-`, `Multiply`, `Multiply`, `Add`. For sliding layers `q_in,k_in,v_in` become three separate layer-norm results (3x RMSNorm+AsType) instead of one shared. 110 extra prims per visit with 4 gates. [glue a, e]
* **Messages per step**: `message_input` (per loop visit): `Slice bank`, `AsType`, `RMSNorm` (the bank's partial = `unweighted_rms_norm(h.f32)`), `Gather query[layer]`, `Squeeze`, `CustomKernel depth_attention` (Q=4) -> (1,1,4,2304) f32. Once per loop pass: `step_bank_pass_0_slice_unweighted_rms` (3).
